Название роли
=========
## gitlab-runner

Роль предназначена для установки на хост gitlab runner и подключения его к gitlab (к self-hosted или gitlab.com).

Поддерживается установка на RedHat-based и Debian-based.

Поддерживаемые executors - docker и shell. Выбор делается с помощью переменных, важное замечание что для устанновки любого из вариантов, необходим интернет так как установка производиться в онлайн режиме, оффлайн не поддерживается.

Переменные роли
--------------
### Прописывается в inventory файле
- `executor:` - Прописывается в inventory файл. Параметр отвечающий за то, какой executror использовать для раннера. Поддерживает следующие значения:
  - `"docker"` - Вкллючает режим когда раннер устанавливается в режиме docker контейнера с пробросом docker.sock
  - `"shell"` - Включает установку раннера как обычной службы использующей shell оболочку для выполнения команд на хосте где он будет установлен  

- `runner_token:` - токен для раннера сгенерированный в gitlab
### Прописывается в defaults/main.yml
- `gitlab_url:` - Указывается ссылка на gitlab к которому должен быть подключен раннер
- `custom_ca:` - Принимает `true` или `false`, нужно установить `true` если используется self-hosted версия gitlab и при этом кастомные самоподписанные сертификаты для https
- `custom_ca_cert:` - В этой переменной, указывается имя кастомного самоподписаного сертификата для самого сервера gitlab, который должен будет быть установлен в систему для корректного подключения runner по `https`. Сам сертификат необходимо положить в директорию `files/`

Содержимое tasks
--------------
- runner_container.yml - Устанавливает docker и пулит образ gitlab-runner для docker, так же при наличие сертификата, настраивает контейнер на работу с ним. Выполняется только в случае, если executor = docker
- runner_shell.yml - Устанавливает ключи и репозитории gitlab для скачивания gitlab-runner, так же устанавливает его в систему, настраивает при наличие доверие системы к сертификату gitlab. Выполняется только в случае, если executor = shell
- runner_register.yml - Регистрирует gitlab-runner на инстансе gitlab
- runner_conf.yml - конфигурирует gitlab-runner для корректной работы в docker. Выполняется только в случае, если executor = docker

Содержимое handlers
--------------
- main.yml:
  - `update ca debian` - Обновляет локальное хранилище доверенных сертификатов для Debian-based систем
  - `update ca redhat` - Обновляет локальное хранилище доверенных сертификатов для RedHat-based систем
